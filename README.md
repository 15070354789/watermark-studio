# 印记 · 批量图片水印

一个中文图片水印工具，支持文字和 Logo 水印、自由拖动、实时预览、批量下载。图片只在自己的浏览器里处理，无需注册，也无需上传服务器。

## 使用

1. 添加 JPG、PNG 或 WebP 图片，可拖入或分批选择。
2. 输入水印文字，或上传 Logo。调整大小、透明度、旋转角度，在预览图上直接拖动水印。
3. 点击「下载全部图片」，默认下载独立图片，无需解压；也可选择 ZIP 打包。

如果浏览器提示，请允许下载多个文件；也可以展开已生成的文件列表逐张补下。

## 功能

- 文字水印：字体、颜色、柔和阴影、多行文字。
- Logo 水印：自动去除外围透明空白，按可见图案定位。
- 水印大小为图片短边的 1–100%；超出画面时自动适配。
- 鼠标或触摸拖动；输入水平／垂直百分比精确定位；方向键微调，Shift + 方向键加速。
- 九宫格快捷位置、全图平铺。边缘留白设为 0% 时可贴边。
- 水印位置按比例应用到整批图片，适配不同尺寸。
- 保留原始像素尺寸，跟随原格式或转换为 JPG、PNG、WebP。
- 独立图片下载、ZIP 打包、下载当前图片；导出期间可取消。
- 手动保存文字设置，下次在同一浏览器恢复。

## 本地运行

直接用现代浏览器打开 `index.html` 即可。也可以在项目根目录运行：

```bash
python -m http.server 8765
```

然后打开 `http://localhost:8765`。项目没有运行依赖，不需要安装 npm 包。

## 发布到 GitHub Pages

在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/(root)**，保存即可。以后推送到 `main` 会自动更新网页。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 中文界面与使用指南 |
| `style.css` | 响应式布局 |
| `app.js` | 导入、预览、水印渲染、下载与设置 |
| `geometry.js` | 预览、拖动、导出共用的水印位置计算 |
| `zip.js` | 无依赖 ZIP 打包，支持中文文件名与 CRC-32 |
| `tests/geometry.test.cjs` | 缩放一致性、旋转、贴边、透明边距回归测试 |

有 Node.js 时可运行测试：

```bash
node tests/geometry.test.cjs
```

## 限制与数据

- 每批最多 100 张，总计不超过 200 MB；单张最多 4000 万像素。
- Logo 最大 10 MB、2000 万像素；完全透明的 Logo 会提示重新选择。
- 每批输出累计最多 512 MB，超限图片会提示，可分批处理。
- PNG 保留透明背景；JPG 会将透明区域填白。静态导出不保留 EXIF 或动画。
- 原始文件不会修改，导出文件名增加 `_watermarked`；同名输出自动加数字后缀。
- 图片和 Logo 不持久保存，刷新后需重新添加。保存的文字设置仅留在本地浏览器。
- 页面不能判断浏览器是否已保存下载文件；生成列表提供逐张下载入口，保留到下次批量导出或关闭页面。

## 已验证

浏览器验证 JPG、PNG、WebP 独立批量下载与 ZIP 导出、停止自动下载后补下、Logo 透明边距裁剪、自由位置与贴边。实际导出的独立图片与同批 ZIP 内容一致，原始尺寸、PNG 透明度和水印效果均已校验。
