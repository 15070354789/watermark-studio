# 印记 · 批量图片水印

一个中文图片水印工具，支持文字和 Logo 水印、自由拖动、实时预览、批量下载。图片只在自己的浏览器里处理，无需注册，也无需上传服务器。

**[直接打开网页版](https://15070354789.github.io/watermark-studio/)** · **[查看源码](https://github.com/15070354789/watermark-studio)**

## 使用

1. 添加 JPG、PNG 或 WebP 图片，可拖入或分批选择。
2. 输入水印文字，或上传 Logo。调整大小、透明度、旋转角度，在预览图上直接拖动水印。
3. 点击「下载全部图片」，默认下载独立图片，无需解压；也可选择 ZIP 打包。

如果浏览器提示，请允许下载多个文件；也可以展开已生成的文件列表逐张补下。

## 功能

- 文字水印：字体、颜色、柔和阴影、多行文字。
- Logo 水印：自动去除外围透明空白，按可见图案定位。
- 水印大小为图片短边的 1–100%；超出画面时自动适配。
- 鼠标或触摸拖动；输入水平／垂直百分比精确定位；方向键微调，Shift + 方向键加速。
- 九宫格快捷位置、横向平铺、斜向平铺；旋转角度调整斜度。边缘留白设为 0% 时可贴边。
- 平铺时可自动避开商品或人物主体，每张图片独立识别。可查看识别范围，绿色提示仅用于预览。
- 识别失败时可「手动标记主体」：保护画笔、框选主体、橡皮擦、撤销和清空；也可在自动识别结果上补画、擦除。手动区域每张图片独立保存，优先用于该图导出，无需联网或下载模型。
- 水印位置按比例应用到整批图片，适配不同尺寸。
- 默认以 PNG 无损编码导出，保留原始像素尺寸与透明背景；也可选择跟随原格式、JPG 或 WebP。
- 独立图片下载、ZIP 打包、下载当前图片；导出期间可取消。
- 手动保存文字设置，下次在同一浏览器恢复。

## 本地运行

在项目根目录运行静态服务器（主体识别 Worker 需要 HTTP / HTTPS）：

```bash
python -m http.server 8765
```

然后打开 `http://localhost:8765`。不需要安装 npm 包。普通水印无需联网；首次开启主体识别会从 jsDelivr 下载 Transformers.js 3.8.1，并从 Hugging Face 下载约 44 MB 的模型权重及运行组件，后续优先使用浏览器缓存。图片像素只在浏览器内计算，不发送给这些服务。网络无法访问模型时会提示重试，开启主体保护的图片不会降级为无遮罩导出。

主体识别采用 Apache-2.0 许可的 [ISNet general use ONNX](https://huggingface.co/Ko033/isnet-general-use-onnx)，固定模型版本 `5349b617911fd60c619b52f32e2b593517b78df3`，通过 Web Worker + ONNX Runtime WASM 运行。识别输入最长边为 1024 像素，原图导出仍保留原始尺寸。识别蒙版最多缓存八张；批量导出逐张识别。

## 发布到 GitHub Pages

在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/(root)**，保存即可。以后推送到 `main` 会自动更新网页。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 中文界面与使用指南 |
| `style.css` | 响应式布局 |
| `app.js` | 导入、预览、水印渲染、下载与设置 |
| `geometry.js` | 预览、拖动、导出共用的水印位置计算 |
| `subject.js` | 主体蒙版缓存、轮廓保护和 Worker 请求 |
| `subject-worker.js` | 下载公开模型，在本地推理商品和人物轮廓 |
| `manual-mask.js` | 每张图片独立的手动蒙版、画笔／框选／擦除、撤销与取消 |
| `zip.js` | 无依赖 ZIP 打包，支持中文文件名与 CRC-32 |
| `tests/geometry.test.cjs` | 缩放一致性、旋转、贴边、透明边距回归测试 |

有 Node.js 时可运行测试：

```bash
node tests/geometry.test.cjs
node tests/tiling.test.cjs
```

## 限制与数据

- 每批最多 100 张，总计不超过 200 MB；单张最多 4000 万像素。
- Logo 最大 10 MB、2000 万像素；完全透明的 Logo 会提示重新选择。
- 每批输出累计最多 512 MB，超限图片会提示，可分批处理。
- PNG 保留透明背景，不受 JPEG／WebP 编码质量参数影响，文件通常更大；JPG 会将透明区域填白。静态导出不保留 EXIF 或动画。
- 原始文件不会修改，导出文件名增加 `_watermarked`；同名输出自动加数字后缀。
- 图片和 Logo 不持久保存，刷新后需重新添加。保存的文字设置仅留在本地浏览器。
- 页面不能判断浏览器是否已保存下载文件；生成列表提供逐张下载入口，保留到下次批量导出或关闭页面。
- 主体识别需要联网获取模型，首次耗时取决于网络与设备性能；复杂背景、多主体或小物体可能漏识别，请查看识别范围。识别失败的图片会列为导出失败；其余成功图片可以正常导出。
- 自动识别失败时，可以先手动标记再导出。编辑时绿色区域受保护，工具栏位于预览图上方；画笔支持方向键移动、Enter 涂抹。手动区域只属于当前图片，切换图片或批量导出时不会套用给其他图片；刷新或移除图片会清除它。取消修改会恢复进入编辑前的区域；清空可撤销。没有标记任何区域时无法完成保存。

## 已验证

浏览器验证 JPG、PNG、WebP 独立批量下载与 ZIP 导出、停止自动下载后补下、Logo 透明边距裁剪、自由位置与贴边。实际导出的独立图片与同批 ZIP 内容一致，原始尺寸、PNG 透明度和水印效果均已校验。

通用主体识别已用汽车与人物照片在浏览器中执行真实模型推理。斜铺导出的 PNG 主体内部像素与原图保持一致（允许不同 JPEG 解码器的微小差异），背景水印保留；绿色识别提示未出现在导出文件中。单张与批量结果字节一致。识别并不保证所有复杂图片都准确。

浏览器实际导出验证手动框选、画笔、橡皮擦、撤销、清空撤销、取消修改、逐图独立区域。800×600 与 400×300 PNG 保留原始尺寸和透明度，手动区域内水印去除，绿色编辑提示不导出；撤销后图片与原结果字节一致。手动区域也可直接接替自动识别。


Logo 平铺间距默认为图片短边的 4%。Logo、文字的平铺间距和单个水印的边缘留白分别记忆；调整后点击「保存当前设置」可在下次继续使用。
